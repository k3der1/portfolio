02 / ВОЗМОЖНОСТИ

Что умеет бот.

01

Меню и команды

/start /about /skills /projects /contact /help. Кнопки + инлайн-ссылки на сайт и GitHub.

02

Заявка за 3 шага

FSM: имя → контакт → задача. Отмена по /cancel. Проверка пустых ответов.

03

База + админка

SQLite: leads.db. Команда /leads только для админа. Уведомление о новой заявке в личку.

03 / КОД

Как это устроено.

bot.py · aiogram 3
@router.message(CommandStart())
async def cmd_start(msg: Message, state: FSMContext):
    await state.clear()
    await msg.answer("Привет! Я — бот-портфолио...",
                     reply_markup=main_kb())

@router.message(LeadForm.task)
async def lead_task(msg: Message, state: FSMContext):
    data = await state.get_data()
    lid = db_save(data["name"], data["contact"],
                  msg.text, msg.from_user.username)
    await msg.answer(f"Готово, заявка #{lid} сохранена!")

04 / ВОПРОСЫ

Частые вопросы.

Сколько времени займёт мой бот?+

Простой бот с заявками: от 3 дней. С каталогом, рассылкой или онлайн-оплатой: одна-две недели. Точный срок назову, как только расскажешь задачу.

Что нужно от меня на старте?+

Просто опиши задачу своими словами: кто будет пользоваться ботом и что он должен делать. Тексты, логотип и доступы соберём по ходу.

Как проходит оплата?+

50% перед началом работы и 50% после сдачи. Для крупных проектов можно поэтапно. Работаю по договорённости, договор и чек — по запросу.

А если бот сломается после запуска?+

Две недели после сдачи исправляю баги бесплатно, дальше поддержка по договорённости. Бот живёт на твоём хостинге и твоём токене, так что ты ни к чему не привязан.
